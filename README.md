# شیشه‌ی نیایش

نقاشی روی شیشه برای نیایش. خط برجسته، رنگ شفاف، و نور از پشت. همه‌چیز روی همین گوشی می‌ماند.

صفحه را با یک وب‌سرور باز کن:

```
python -m http.server 8942
```

بعد برو به `http://localhost:8942`.

نقاشی‌ها در IndexedDB همین مرورگر هستند. اگر اطلاعات مرورگر پاک شود از بین می‌روند؛ از گالری یک پشتیبان JSON بگیر.
